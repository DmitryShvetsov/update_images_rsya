<h1>Автоматическое заполнение изображений в объявлениях Яндекс.Директа</h1>

I Ищем ссылку перехода на страницу первого товара По этим данным скрипт будет находить ссылку первого товара на странице для последующего скачивания изображения с карточки товара. На карточке товара обычно большое изображение, а в листинге категории только небольшая картинка - превью.

1. Нажимаем правой мышкой на первый товар раздела и копируем ссылку на карточку товара.

2. Скачиваем исходный код страницы раздела сайта (ctrl+u в браузере).

3. Находим ссылку на карточку товара в исходном коде и выделяем символы, которые находятся слева от ссылки. Например, это «data-hover-gallery>».

При поиске учтите, что в исходном коде ссылка будет без домена.

4. Вставляем это значения в файле ad_id_hash_from_page.py в переменную prod_page_pattern.

II Ищем изображение товара Теперь на карточке товара надо найти тег, после которого начинается ссылка на изображение.

1. Переходим в карточку товара.

2. Правой мышкой открываем изображение первого товара. Копируем из url ссылку на изображение.

3. Находим ссылку изображения товара в исходном коде страницы товара и выделяем символы, которые ограничивают её слева и справа. Например, «'».

4. Вносим найденные значения в переменные page_text_from и page_texts_to соответственно


III Парсим картинки Сначала надо заполонить 3 переменные в файле config.py:

login_direct = "your-login"
token_direct = "your-token"
host = "https://www.you-site.ru/product/" 


Запускаем наш питоновский скрипт ad_id_hash_from_page.py, который создаст json-файл, в котором будут id объявлений и хэш-коды изображений.

Учтите, что скрипт выравнивает картинки до квадратной формы, путем добавления белых полей. Иначе Директ может не принять изображение либо оно будет обрезаться при показах.

IV Обновляем картинки в объявлениях
Запускаем скрипт ads_update.py, который на основе полученных данных присвоит объявлениям новые изображения. 

Далее проверяем полученный результат в кабинете. 
<br clear="left">
На всякий случай, рекомендуется сначала проверить на одной тестовой РК. Для этого обратите внимание на переменную «camp_ids_filter».
